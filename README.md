### 🔌 Essential MCP Servers

#### 🗄️ Databases & Cloud
*   **[Supabase / Postgres MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/postgres)** - The standard for connecting AI models to live, transactional database structures. Read, write, and analyze schema directly.
*   **[SQLite MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/sqlite)** - For lightweight, local persistent memory for agents. Ideal for building agentic memory loops.
*   **[MySQL MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/mysql)** - Direct MySQL database interactions for legacy enterprise systems.
*   **[Neo4j MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/neo4j)** - Graph database MCP for mapping complex relationship architectures (e.g. tracking agentic interactions).

#### 🛠️ Development & DevOps
*   **[GitHub MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/github)** - The most critical server for enabling agents to interact with repositories, PRs, and issues natively.
*   **[GitLab MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/gitlab)** - Enterprise-grade version control integration.
*   **[Sentry MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/sentry)** - Allows AI agents to ingest and analyze production error logs in real-time.
*   **[AWS MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/aws)** - Manage S3 buckets, EC2 instances, and Lambda functions via agentic orchestration.
*   **[Docker MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/docker)** - Spin up, tear down, and manage containers dynamically from prompt.

#### 🌐 Browser Automation & Testing
*   **[Puppeteer MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/puppeteer)** - Excellent for allowing agents to autonomously navigate the web, test UIs, and scrape dynamic pages.
*   **[Brave Search MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/brave-search)** - High-quality web search API optimized for LLMs. Perfect for RAG.
*   **[Fetch MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/fetch)** - Basic HTTP/REST API interactions without a heavy browser overhead.

#### 📚 Productivity, Context & Docs
*   **[Google Drive MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/gdrive)** - Read and analyze company documents directly from Google Workspace.
*   **[Slack MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/slack)** - Let agents read channel context and post updates automatically.
*   **[Figma MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/figma)** - For design-to-code workflows. Extract CSS tokens and layout structures.

*   **[Confluence MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/confluence)** - Enterprise knowledge base integration.

#### 🧠 Agentic Memory & Utilities
*   **[Agent Payment Node](https://github.com/nuanu-ai/agent-payment-node)** - Local macOS CLI and stdio MCP payments with foreground owner approval for signing.
*   **[Memory MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/memory)** - Knowledge graph-based persistent memory for AI models.
